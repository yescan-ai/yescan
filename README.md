## 平台简介

夸克扫描王开放平台是阿里巴巴智能信息事业群旗下的 AI 文档处理 PaaS 平台，源自夸克扫描王 App 数亿用户的核心 AI 技术沉淀。

平台面向 B 端开发者和企业，提供 **36 项 AI 能力**，涵盖文字识别（OCR）、文件扫描增强、格式转换、AI 证件照生成四大类，支持 **20+ 种语言** 识别，日处理量可达千万级。

**一个 API，36 项能力** — 所有能力通过统一的 Vision API 端点访问，开发者只需切换参数即可调用不同能力，极大降低集成成本。

## 五种接入方式

### 方式一：API 直接接入（推荐）

最标准的接入方式，适合有后端开发能力的团队直接嵌入业务系统。

```
POST https://scan-business.quark.cn/vision
Content-Type: application/json
```

**Python 代码示例**：

```python
from time import time
import requests, uuid, hashlib

client_id = "your-client-id"
client_secret = "your-client-secret"
sign_nonce = uuid.uuid4().hex
timestamp = int(time() * 1000)

# SHA3-256 签名
raw = f"{client_id}_vision_SHA3-256_{sign_nonce}_{timestamp}_{client_secret}"
signature = hashlib.sha3_256(raw.encode("utf-8")).hexdigest()

resp = requests.post("https://scan-business.quark.cn/vision", json={
    "dataUrl": "https://example.com/document.jpg",
    "dataType": "image",
    "serviceOption": "ocr",
    "inputConfigs": '{"function_option":"RecognizeGeneralDocument"}',
    "clientId": client_id,
    "signMethod": "SHA3-256",
    "signNonce": sign_nonce,
    "timestamp": timestamp,
    "signature": signature
})
print(resp.json())
```

### 方式四：CLI 命令行接入

开发者友好的命令行工具，适合脚本化处理和快速测试。

```bash
# 安装
pip install yescan

# 配置 API Key
yescan config set SCAN_WEBSERVICE_KEY your-api-key

# 使用 —— 场景名一键调用
yescan -s general-ocr -p ./document.jpg          # 通用OCR
yescan -s idcard-ocr -p ./id_card.jpg             # 身份证识别
yescan -s image-to-word -p ./paper.jpg -o ./out/  # 图片转Word
yescan -s remove-watermark -p ./watermarked.jpg   # 去水印
yescan --list-scenes                               # 查看所有可用场景
```

## 常见问题

### Q：一个 API Key 可以调用所有能力吗？
A：是的。所有 36 项能力共用同一个 API Key，通过 `serviceOption` + `function_option` 参数切换不同能力。

### Q：是否支持 PDF 输入？
A：部分能力支持 PDF 输入（如通用文字识别），具体以各能力文档说明为准。图片输入为主推方式。

### Q：QPS 限制是多少？
A：根据套餐类型有不同的 QPS 配额。如需高并发，可联系商务定制方案。

### Q：数据安全如何保证？
A：采用 SHA3-256 签名鉴权，传输层 HTTPS 加密，支持文件不落盘选项，符合企业级数据安全规范。

### Q：出现错误怎么排查？
A：请参照错误码表：

| 错误码 | 含义 | 解决方案 |
|--------|------|---------|
| `00000` | 成功 | — |
| `A0100` | 访问未授权 | 检查 API Key 是否正确 |
| `A0202` | 无效时间戳 | 检查客户端时间同步 |
| `A0300` | 超 QPS 限制 | 降频或升级套餐 |
| `A0301` | 超每日调用限制 | 等待次日重置或升级 |
| `A0400` | 图片解析失败 | 检查图片格式和大小 |
| `B0101` | 系统超时 | 重试即可 |
